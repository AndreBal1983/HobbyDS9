# Streamed construction catalogue

Status: source/CPU candidate. Actual Unity layout, interaction and native
acceptance remain pending. This implements the owner's sectioned-catalogue and
direct + direction from 25 October 2026 using the existing streamed campaign.

The World construction page shows Ships, Planetary buildings, Special projects
and System improvements together, with the selected own world's mixed FIFO on
the right. Ships come from actual actor-owned publications, including the three
initial ready classes and exact older/custom revisions with their support reason.
Buildings are the three actual authored structures. The other sections state
that no buildable options exist in this campaign; mockup content is not adopted.

Inspect changes only local selection. + requests one enqueue immediately, without
preview/Confirm, using a new command ID and the original observed actor/stamp,
exact world, definition and revision. The panel latches and disables additions
before the callback. The unchanged asynchronous Submission path performs shared
authoritative validation on a private candidate and commits once. Rejection does
not retry or change the live queue. Busy, stale source, disposal/cancellation,
dirty drafts and late completion retain the accepted interaction-worker behavior.
Expedition and destructive cancellation actions still have their existing review.
Earlier profiles retain their original panels and command behavior.

Construction feedback is a separate scoped presentation string, not a general
echo of the model message. It binds exact current controller/frame, world and
operation ID; weak identities retain no old session. Fresh catalogue redraw and
same-controller resize show its actual status label. Another world/session/frame
does not inherit it. Starting a new operation clears it; stale completion and
Busy Begin rejection cannot overwrite newer feedback. A nonbusy rejected Begin
updates the current owned label without recapturing a potentially stale frame.
No rejection is automatically retried. Actual visible negative feedback remains
part of the later Unity receiving gate.

Each authored structure is unique per colony under the existing rule: its tile
shows actual installed and queued counts, and + is disabled when built or queued.
Material shortage does not prevent queueing. No credits are charged for normal
construction; progressive local consumption, actual delivery and interruptions
remain governed by [the streamed production contract](campaign-activities-streamed-v1.md).
No reorder, buyout, repeated buildings, guaranteed ETA or new production kind is
introduced.

`CaptureStreamedActivities(actor).Construction` contains only own colony facts.
Current Industry/Research/Food is the actual WorldEconomy projection, with actual
installed counts. Independent hypothetical projections use detached colony
copies: current plus one, all pending structures together, pending plus one.
They rerun the same integer/power/politics calculation rather than adding nominal
bonuses. Current rules scale Industry by power, not Research/Food uniformly.
Queued buildings are not current capacity. Conditional forecasts hold current
population, politics and other determinants fixed and assume eventual completion.

Expected hypothetical arithmetic overflow yields a typed ArithmeticOverflow
status, null output and stable reason. It never clamps values, hides valid current
output, or makes an otherwise valid command unsupported. Only OverflowException
inside those hypothetical calculations is caught; current/source invariant faults
retain their ordinary behavior. These DTOs are detached observations, not saved
fields, permission tokens or a new content/profile identity.

The native catalogue and queue have separate scroll surfaces. Inspection can
collapse; its single lazy exact-hull stage keeps the existing art provenance and
disposal policy. Tile names never infer visual/stat identity. Only strings,
selection flags, scroll offsets and focus identity survive a same-controller/
actor redraw. No captured command, eligibility, callback or old view is retained.
Inactive and disposed catalogue actions cannot submit or open cancellation review.

Source/CPU checks cover query purity/privacy/copy isolation, real unique-building
queue/cancel/completion/reload, combined nonlinear output and independent
hypothetical overflow with unchanged admission. A direct worker submission test
uses no preview, proves Busy/one-use/stale rejection, full synchronous equivalence,
zero normal credit/Planning material charge and exact typed Continue. Actual
per-size + hit targets, inactive/disposed callbacks, scrolling/focus and hull
inspection will be checked in the existing receiving journey after source review;
reference compilation alone does not establish those UI outcomes.
