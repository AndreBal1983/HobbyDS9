## Route queries — separate commit and policy

Add `FindRoutePlan(GalaxyReviewRouteQueryDto)` to GeneratedGalaxyReview, EnvironmentGalaxyReview, ScaledGalaxyReview and new NaturalGalaxyReview. Existing `FindRoute(origin,destination)` retains its exact old ordinal-BFS behavior. Old maps/Open/route fixtures are not silently changed by the new query API.

The explicit policy `minimum-crossings-centre-span-v1` orders alternatives by: (1) minimum unit-cost crossings; (2) minimum sum of **floor integer Euclidean lengths between consecutive region centres**; (3) ordinal comparison of the entire node sequence. All arithmetic is integer and deterministic. Shortest-cost BFS layers form an acyclic search graph, then secondary-cost dynamic programming chooses within that graph. This is a geographic directness proxy, **not actual smoothed-portal length, physical travel time, minimum bends or a globally shortest taut corridor**. A geometrically longer route still wins when it saves a crossing. No density/nebula surcharge.

Request fields are in Contracts/GalaxyReviewRouteContracts.cs. PolicyVersion and MapContentHash are explicit; a stale map rejects before search. OriginNodeId plus ordered Targets (maximum64, including final destination last) describe all legs. Each target has NodeId, Intent and nullable SystemId. RegionTransit requires no SystemId and is only a region constraint. SystemVisit requires the exact associated system identity; it expresses draft intent, **not an executed visit/scout/order/action**. Passing an ordinary intermediate system region has no visit semantics. Manual target positions/painting belong to the frontend; the portable query identifies regions and supported system intents.

Filter is mandatory with explicit PermittedNodeIds/PermittedConnectionIds: at most2000/6000distinct known IDs. Missing lists reject, empty lists grant nothing. Full-map review explicitly supplies the entire map's IDs. Before search, construct the permitted subgraph; apply the same filter to every waypoint leg. This is a tested future seam, not an actor authorization provider or a privacy-safe campaign knowledge API. Do not derive sensor/access/foreign-actor facts or trust a persisted filter as permission.

Result is immutable and stamped with map hash/policy. Success returns ordered Legs with OriginNodeId, typed Target, existing StrategicRouteSnapshot (Steps excludes that leg's origin), per-leg geographic proxy, flattened Steps, aggregate TotalCost and GeographicLengthUnits. Repeated manual nodes/zero-length legs are allowed and remain meaningful ordered targets. Failure returns ErrorCode/zero-based FailedLegIndex where applicable, **no successful prefix legs/steps or aggregate costs**. Query never mutates the map, hash, RNG or an existing draft. Host draft replacement remains atomic.
