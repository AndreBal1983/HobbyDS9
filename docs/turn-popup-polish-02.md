# Turn completion presentation

15 November 2026. Source candidate; physical/native acceptance pending.

Completion dialogs keep the existing LCARS modal, ordered queue, acknowledgment/deduplication and source-frame guards. Discovery identity and level are the heading; current level/progress is shown from the current Science snapshot. Owned vector icons use the actual discipline enum, or Engineering/structure completion kinds. Resolved week and event index are secondary metadata. The repeated generic Engineering-eligibility sentence is removed.

Research notices list **Available Engineering** only when the current authoritative cards report CanTarget and the output is supported by this campaign. This includes all Science and project prerequisites; it is not guessed from the discovery's discipline. The wording does not claim newly unlocked work because the list is current availability, not a before/after attribution. The contextual Open Engineering action acknowledges the notice and navigates to the relevant project/category without starting or spending. If no projects are available, it says so and retains useful Science inspection.

Next/Close, focus return, background exclusion, stale rejection, queue ordering and replay/load silence remain. No reward, execution rule or persisted acknowledgment is added. Existing queue/receipt portable cases and actual prerequisite eligibility cases cover the data; the real dialog/icon/navigation layout remains a QA gate.
