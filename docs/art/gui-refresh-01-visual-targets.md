## Shared LCARS receiving rules

Use established structural elbows/segmented rails and native type/control geometry. The accepted LCARS foundation gives44px buttons,8px segment gap,16px padding/12px inner gap,18px text/24px sections,30px structural bar and22px pill radius. The later PlayerConsole/C concepts adapt these to the current campaign shell; apply the same grammar rather than pasting every historical layout verbatim.
