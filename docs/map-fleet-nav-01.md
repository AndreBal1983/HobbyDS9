# Fleet ring inspection

15 November 2026. Source candidate; native/physical input acceptance pending.

One completed left click retains the existing own-fleet selection. A second completed click must hit the same ring/node in the same current frame and pointer chain; it then opens Fleet Orders. A singleton selects its exact FleetId and expanded details. An aggregate opens the existing lawful roster with no arbitrary fleet selected, so the player chooses. Standard guarded keyboard activation, including Enter, inspects the same ring.

The ring owns its pointer capture and stops propagation to the underlying star. Drag distance, cancel, zoom/pan/fit, context click, frame changes, modal disable and detached controls reject the inspection chain. Current actor-owned fleet snapshots supply the IDs; contact markers are not redirected into hidden enemy rosters. No route, order, turn, publication or discard command is submitted. Local drafts survive navigation.

The dedicated engine fixture exercises actual ring picking/layer, single/double click, exact/aggregate roster selection, retained dirty state, drag and stale-frame rejection. Existing guarded-key tests now expect inspection and verify a held Enter does not activate a replacement control. These are source-authored/compiled until QA executes them.
