## Minimal additive API seam — implemented, no gameplay change

`CampaignIntegratedStrategySnapshot.References` adds immutable names/definitions for owned cohort species, installed infrastructure, resources used by stocks/design costs, and public policy/memory definitions. No foreign colonies/population/political values/intentions or unfiltered root is returned. Existing numeric facts remain unchanged.

`ICampaignIntegratedPlaytestSession.CaptureDesignLibrary(string actor)` returns `CampaignIntegratedDesignLibrarySnapshot { Actor, Status, Catalogue, Published, CanPublish, CanConstructPublishedBlueprints }`. Catalogue is the existing `CampaignShipDesignCatalogueSnapshot` with real `AvailableVersionIds`; Published is only that controlled actor's immutable `CampaignBlueprintSnapshot` revisions. `CanConstructPublishedBlueprints` is explicitly **false**. Unknown/uncontrolled actors reject. Publication still uses existing observed-stamp `CommandEnvelope.PublishShipBlueprint` through `SubmitStrategicCommand`; costs/stats are compiler-owned and no client compiled payload is accepted. No second session or catalogue-based implicit equipment conversion.
