# Second frontier mission: portable implementation

Status: source/CPU candidate pending final review. No player, codec, slot, Resources, Unity or native activation is included. The named policy is provisional engineering scope, not a claim of finished strategic AI.

The explicit `CreateRepeatPackage` / `StartRepeatGame` / `LoadRepeatSave` / `ExportRepeatSave` APIs own a new Format13 root and trusted private source edition. The complete root retains the original first-colony/Growth plan and adds one separate second establish-only assignment per actual AI actor. The second Settlement manifest ID is write-once; there is no third mission or second immigration goal. Package composition produces mutable DTOs as existing factories do; Start and Load establish the detached owned boundary. Supplied package hashes must match the closed source, and complete normal replay compares both plan collections and the entire base campaign. Every older complete export remains rejected for this edition.

The first plan owns the shared eight-attempt/four-accepted-action weekly ledger and canonical actor-ordinal command IDs. Both assignments share bounded route searches. Accepted action adoption is followed by reacquiring owned assignments. The same construction, survey, fleet organisation, embark, movement, deployment, survival and unloading kernels remain authoritative. The second expedition needs an actual new kit, actual 100 people and finite carried food. It reuses a real installed-capability R1 transport where available and otherwise pays for ordinary construction.

Actual loaded cargo handling and all retained populated owned camp food deficits precede discretionary second activation. `SupplyCampId` is a persisted own-camp commitment set in the accepted loading candidate and retained across movement; the physical manifest's ship remains authority. A source must be distinct from its receiver and have positive resident-reserved food. Supply can continue after either mission closes; closing the second mission never erases first-colony history. Missing carriers hold for the normal survival boundary. A suspended second mission releases discretionary ship and kit/yard reservations; actual loaded cargo, active surveys and retained-colony urgent support still reserve their real resources. There is no conquest writer in this increment: foreign ownership poisons fail closed and cannot provide current food access. Ownership-loss defensive fixtures are not claimed as legal conquest histories.

Fixed preflight headroom is 512 visits and 256 KiB per actual AI actor, plus 64 visits and 16 KiB outer overhead, from genesis through terminal closure. Maximum four actors, eight shared receipts, eight attempted targets per assignment and bounded strings are enforced before base copying. The maximal typed graph tests count keys as additional work and use escaped strings and maximum integer widths; exact fit/one-below and empty/full four-actor tests guard the reservation. Existing two-million-visit/64-MiB ceilings and the original Format11 visitor remain unchanged. Existing finite journal/record/entity-ID protection is retained; it is not a universal future-Advance liveness guarantee.

The normal unmodified 250-system seed42 journey establishes a distinct second colony at turn51, using real streamed production, a real kit and transported people. Queue, loaded, movement-boundary, supply, founding and established roots are checked through full Format13 replay. The voyage completes within its weekly movement boundary; no persisted in-flight second-voyage root is claimed. MovementProof input/order and actual edge-completion receipts prove the crossing. Isolated counter, population redistribution, ownership poison, carrier loss and recovery-trigger fixtures are defensive tests, distinct from this public journey. Prior fixture/expectation failures are preserved in the external receipt packet.

The original Growth/Expansion DTOs, enums, defaults, source identities and byte behavior are unchanged. Final acceptance additionally requires historical full-load/whole-byte proofs and relevant regression receipts.
