# Format12 replay phase diagnostics

Implemented: optional measurement only. No performance optimization or timing benchmark is claimed.

`CampaignColonisationExpansionApplication.LoadSave(package, root)` remains the normal entry. It passes null diagnostics and creates no timing accumulator. The overload `LoadSave(package, root, out ColonisationLoadTimingReport? report)` performs the same complete load and returns a detached immutable observation. This report is outside persisted Contracts; it grants no admission or command authority.

The internal `ColonisationReplayTiming` accumulator belongs to that invocation only. No callback, static collector, session field, file writer or cross-load approval cache exists. Seven closed phases are recorded: expansion preflight, core preflight, frozen-map validation, initial-state construction, journal replay, core export/equality and expansion export/equality. Clock ticks use the report's StopwatchFrequency. Timings are inclusive of each phase's internal work and are non-additive with any enclosing wall-time measurements. They do not isolate allocations, CPU time, IO, UI publication or individual fork/validation calls.

Each phase is NotReached, Returned or Failed in a completed report. Active is an internal intermediate state; the loader's finally closes outstanding phases on failure before the Application snapshots them. Diagnostic clock/count/snapshot failures are shielded only around diagnostic operations, never around validation. A failed diagnostic allocation/snapshot may leave the nullable report null. Original rule failures still escape with their existing type/message.

Ten fixed operation keys count Unclassified, Colonisation, Activity, Organization, Travel, Strategic, Cloak, Advance, Round and Finalize. Attempted increments before journal closure checks. Accepted/Refused describe a returned mutation result; an exception or malformed closure is neither. EqualityVerified increments only after acceptance and exact journal equality pass. Thus accepted is not synonymous with a fully admitted operation. A malformed root rejected in preflight may have zero attempted counts. Terminal and accepted no-op boundaries retain their actual operation kind; this diagnostic does not invent a semantic no-op classification or log IDs, command text, AI targets or root facts.

The public immutable report copies fixed cells into read-only collections, retaining no accumulator, package, root, session or delegate. Full ordered replay, all package/root/map/budget/source checks, mutation transactions, final whole-root equality, and existing exception behavior remain in place. UI/host/store/codec/content/version and legacy serialization are unchanged.

Focused CPU verification covers whole-export/default parity, input/package immutability, AI-state tamper, reversed journal and malformed operation rejection with identical exceptions, honest refused/failed counts, concurrent report isolation, no timing fields on sessions, read-only output and closed enum agreement. The default entrypoint IL check confirms it does not directly construct an accumulator; the null downstream branch is also source-reviewed, rather than claiming total zero allocation for a load.
