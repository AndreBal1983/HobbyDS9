# Published construction provisional playtest support

This named revision is explicit reversible demo tuning approved for the opt-in
published-construction playtest. It is not final balance and does not alter any
existing catalogue, unlock, design cost, power allocation, crew or mount rule.
`BalanceStatus` retains the support compiler's required `provisional-test-only`
wire value; the catalogue identity is `support.playtest.utility-escort.v1` R1.

The exact table is intentionally small: utility hull; reactor, command, life
support and propulsion; optional energy bank with fully powered escort targeting
sensors. Armor0, base capabilities30/20/20/20/30, targeting40, beam7/6500/4200,
two opportunities every two rounds starting at1 are provisional authored ratings.
No cloak, torpedo, shields, free ammunition or unmapped components are granted.
Classes outside this table may be published but cannot be queued in this mode.

The composition root must load this external table strictly and pin the complete
resulting typed wrapper identity together with its base template and technical
budgets. A saved support identity is never permission to replace that table.
Tests may load this file; runtime code must not call a test fixture factory.
